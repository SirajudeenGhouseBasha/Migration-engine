Practical time to build

One developer, 8-hour days, 5 days a week, working in Cursor with Claude. Hours are hands-on time, including reviewing and testing what Claude writes. Each node above shows its own hours.

  • Shrinks most: well-specified new code such as the runner, the mapping Applier, the validators, the report and the dummy generator (A1, A5, B1 to B7, D1). Claude writes the first pass in minutes. The hours go on tests, seeded defects and review.
  • Barely shrinks: work that waits on a real system. Zoho discovery and throttling (A3, D2) and deploying Lyncs into a new environment (C1, 16 h where the plan has 12 h). C3 stays at the plan figure of 8 h because finding the hooks is fast but proving none were missed is not.
  • C2 and C3 assume the developer already knows the Lyncs codebase. If not, add about 2 days.
  • Not counted: waiting for Zoho API access (the trial may be only 7 days), pilot consent, and the client admin supplying control totals. The Should list is also excluded.

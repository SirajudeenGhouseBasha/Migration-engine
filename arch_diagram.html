Source: §8.2

stateDiagram-v2 [*] --> draft draft --> probing : job gate passed probing --> discovering : capabilities confirmed discovering --> governance_review : inventory, totals, previews ready governance_review --> discovering : scope or dependency check fails governance_review --> approved : client approves approved --> extracting extracting --> mapping : landing zone complete mapping --> staged : mapping set frozen, validated, reconciled staged --> rehearsal rehearsal --> staged : issues found rehearsal --> signed_off : client signs rehearsal signed_off --> frozen : source freeze frozen --> delta delta --> delta : remediate and re-diff delta --> imported_hidden : delta clean imported_hidden --> verifying verifying --> released : signed go/no-go verifying --> rolled_back : no-go released --> hypercare hypercare --> hypercare : compensating correction hypercare --> closed : exit criteria met and decommission gate passed staged --> rolled_back rehearsal --> rolled_back frozen --> rolled_back delta --> rolled_back imported_hidden --> rolled_back rolled_back --> closed closed --> [*] note right of draft paused and failed: from any non-terminal state, return to the prior state (paused_from_status) cancelled and expired: from any non-terminal state, go to closed after cleanup end note note right of rehearsal cutover_runs.run_type = rehearsal end note note right of delta cutover_runs.run_type = delta end note note right of verifying imported_hidden and verifying: run_type = production_hidden end note note right of hypercare released and hypercare: run_type = release end note note right of rolled_back run_type = rollback, closes the job, a re-run is a new job end note 
stateDiagram-v2
    [*] --> draft
    draft --> probing : job gate passed
    probing --> discovering : capabilities confirmed
    discovering --> governance_review : inventory, totals, previews ready
    governance_review --> discovering : scope or dependency check fails
    governance_review --> approved : client approves
    approved --> extracting
    extracting --> mapping : landing zone complete
    mapping --> staged : mapping set frozen, validated, reconciled
    staged --> rehearsal
    rehearsal --> staged : issues found
    rehearsal --> signed_off : client signs rehearsal
    signed_off --> frozen : source freeze
    frozen --> delta
    delta --> delta : remediate and re-diff
    delta --> imported_hidden : delta clean
    imported_hidden --> verifying
    verifying --> released : signed go/no-go
    verifying --> rolled_back : no-go
    released --> hypercare
    hypercare --> hypercare : compensating correction
    hypercare --> closed : exit criteria met and decommission gate passed
    staged --> rolled_back
    rehearsal --> rolled_back
    frozen --> rolled_back
    delta --> rolled_back
    imported_hidden --> rolled_back
    rolled_back --> closed
    closed --> [*]
